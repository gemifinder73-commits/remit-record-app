# Remit Record App

Ang **Remit Record** ay isang Android application na ginagamit para sa mabilis at madaling pag-record at pamamahala ng mga remitans at shift summaries sa bawat branch.

## Features
- Automated In-App Update / Self-Update gamit ang GitHub Releases at Google Sheets API.
- Secure FileProvider APK installation.
- Branch shift summary at transaction tracking.

## Installation
I-download ang pinakabagong bersyon ng APK mula sa [Releases](../../releases) tab at i-install ito sa iyong Android device.
